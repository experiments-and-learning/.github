# Experiments and Learning

A collection of exploratory projects, prototypes, internship work, UI/UX concepts, games, and learning-focused builds created while experimenting with different technologies, frameworks, and development approaches.

## What You'll Find Here

- Backend and full-stack experimentation
- UI/UX design and wireframing projects
- Python and Java mini-projects
- PyGame-based game development
- Academic and internship-related implementations
- Early-stage prototypes and concept builds

## Purpose

This organization serves as a dedicated space for:
- hands-on learning,
- technical experimentation,
- rapid prototyping,
- and documenting growth across multiple domains of software development.

While the primary production-focused and research-oriented projects are maintained separately, the repositories here reflect the broader learning process behind them.

## Areas Explored

- Python Development
- Java Applications
- Game Development with PyGame
- UI/UX Design
- Frontend Prototyping
- Database-Driven Systems
- Applied AI/ML Concepts

## Note

These repositories vary in scope and complexity. Some are polished prototypes, while others are smaller exploratory or learning-oriented implementations built during coursework, internships, and independent experimentation.
